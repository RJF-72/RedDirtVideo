# Red Dirt Video Brand Assets

This directory contains the branded identity for the Red Dirt Video app and product system.

## Files

- `red-dirt-video-icon.svg` — app icon / favicon / square marketing mark
- `red-dirt-video-logo.svg` — primary horizontal logo with icon and wordmark
- `red-dirt-video-wordmark.svg` — wordmark-only lockup
- `red-dirt-video-badge.svg` — circular brand emblem / badge
- `brand-preview.html` — local preview page for visual QA

## Brand direction

The identity blends:
- Texas / Red Dirt country energy
- cinematic production and video creation
- modern SaaS polish
- a warm sunset palette with deep midnight tones

## Suggested palette

- Midnight navy: `#0B1320`
- Deep slate: `#1B2434`
- Fire red: `#E11D48`
- Sunset orange: `#F97316`
- Gold: `#FBBF24`
- Light ivory: `#F8FAFC`

## Usage

- Use the icon for app tiles, favicons, and small interfaces.
- Use the full logo for marketing pages, dashboards, and onboarding.
- Use the badge for avatars, badges, stickers, and venue branding.
